# Установочный пакет B5MShot

Установщик состоит из трёх частей:

- самодостаточного `B5MShot.exe` для Windows x64;
- нативного `B5MShot.ContextMenu.dll`, реализующего `IExplorerCommand`;
- подписанного тестовым сертификатом пакета `B5MShot.msix`, встроенного вместе с публичным сертификатом в `B5MShot-Setup.exe`.

Пакет собирается `MakeAppx`, подписывается `SignTool`, после чего MSIX и публичный сертификат добавляются в ресурсы нативного установщика. Закрытый ключ не хранится в репозитории. Для будущих версий используется сертификат `B5MShot Test Signing` из личного хранилища сертификатов Windows пользователя сборки.

Тестовый установщик требует повышения прав, добавляет публичный сертификат `CN=BU5INESSMAN` в `LocalMachine\TrustedPeople` и устанавливает MSIX. При ошибке установки добавленный сертификат удаляется. Для публичного production-выпуска тестовый сертификат необходимо заменить сертификатом доверенного центра или Azure Artifact Signing.
