# B5MShot 0.8.7 — обновление без лишних вопросов

- Убраны повторные вопросы после нажатия «Обновить» и в установщике. Остаётся системное подтверждение Windows.
- Установщик сам завершает фоновую копию и освобождает отдельный компонент меню B5MShot, который мог удерживать старый пакет и откладывать обновление.
- После установки приложение запускается через механизм активации пакетов Windows; установщик проверяет версию реально запущенного процесса.
- При обычном успешном обновлении больше не появляется завершающее окно с кнопкой OK. Ошибки и предупреждения по-прежнему показываются.
- Открытый редактор защищён: сначала сохраните снимок и закройте редактор. Ручной выход из трея не требуется.

В предыдущих версиях остаётся их собственный вопрос перед запуском установщика до перехода на 0.8.7. Настройки сохраняются.
