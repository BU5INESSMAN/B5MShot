# B5MShot 0.8.3 — исправления установщика

- Вместо общей ошибки «код 1» установщик показывает этап и подробную причину сбоя Windows. Подсказка о закрытии программы появляется только при обнаруженном процессе B5MShot.
- Сбой переноса автозапуска или первого открытия приложения больше не выдаётся за провал уже завершённой установки. Можно открыть установленную программу из меню «Пуск».
- При занятых файлах пакета поддерживается отложенная регистрация Windows. Редакторы, Проводник и другие приложения не закрываются принудительно.
- После успешной или отложенной установки сертификат сохраняется.
- Диагностика сохраняется в `%LOCALAPPDATA%\B5MShot\logs\setup-*.log`; путь к журналу показан в установщике.

Сохраните снимки и завершите B5MShot через трей перед установкой. Подпись пока тестовая.

Общий код 1 из старого установщика сам по себе не позволяет определить причину на конкретном компьютере. Если ошибка останется, новый журнал даст точную причину вместо неподходящей подсказки.
