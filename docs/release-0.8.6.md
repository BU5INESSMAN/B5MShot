# B5MShot 0.8.6 — уведомления и фоновая загрузка обновлений

- Проверка обновлений выполняется после запуска и каждый час.
- Новая версия скачивается в фоне. После загрузки появляется уведомление Windows; проверка больше не открывает окно поверх вашей работы.
- Нажатие на уведомление открывает окно обновления. Уже скачанный установщик используется сразу, после повторной проверки контрольной суммы.
- Закрытие окна обновления не прерывает фоновое скачивание. Если загрузка не удалась, её можно повторить через «Обновления».
- Установка начинается только после вашего подтверждения и при закрытом редакторе. Настройки сохраняются.

Системное подтверждение Windows для установки остаётся необходимым. Часовая проверка и фоновое скачивание начнут работать после установки 0.8.6; предыдущие версии предлагают этот выпуск через свой прежний механизм обновления.
