# B5MShot 0.8.2 — исправление автозапуска

Исправлена ситуация, когда после установки обновления Windows продолжала запускать старую переносимую версию 0.6.0 и снова предлагала обновиться.

- Установщик переносит существующий автозапуск на установленное приложение.
- Команда запуска использует постоянный идентификатор приложения и не зависит от номера версии или папки WindowsApps.
- Настройка автозапуска установленной версии теперь меняет настоящую запись Windows, а не изолированную копию MSIX.
- Если автозапуск был выключен, обновление не включает его. Настройки других приложений не меняются.
- Ошибка доступа к автозапуску не мешает работе трея и захвата экрана.

Перед ручной установкой сохраните снимки и завершите запущенный B5MShot через трей. Установщик подписан прежним тестовым сертификатом; Windows может показать предупреждение.
