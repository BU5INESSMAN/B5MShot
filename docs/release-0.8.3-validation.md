# Проверка установщика 0.8.3

Дата: 28 сентября 2026. Исходники: `5657f652a5f1de43396e93d40118b4cf8cc2fbcf`, тег `v0.8.3`.

## Что удалось установить

Сам по себе старый код процесса PowerShell `1` не указывает причину. Исходный пакет 0.8.2 успешно установлен на чистом hosted Windows runner в проверке `36414210803`. Значит, массовую жалобу нельзя честно свести к одной доказанной причине только по скриншоту.

В старой логике любой сбой после Add-AppxPackage (перенос Run, первый запуск) возвращал ошибку всей установки. При этом новый сертификат удалялся даже после успешного развёртывания. Ошибка занятых ресурсов MSIX также скрывалась за общей подсказкой 1618. Эти сценарии разделены и покрыты тестами.

## Проверки

- Windows PowerShell 5.1: 10 изолированных сценариев в `tests/installer-workflow.ps1`, без изменения настоящих пакетов/процессов/реестра на рабочем ПК. Проверены чистая установка, обновление, работающий редактор, ошибка развёртывания, ошибки миграции и запуска, отложенная регистрация, завершившаяся регистрация, уже более новая версия и неопределённость после развёртывания.
- Реальная установка на чистом hosted Windows runner: подготовительная сборка `36415017023` и финальная `36415248055` — успешно. Тестовая копия установщика собрана из того же C++ исходника, ресурсов и сценария; только модальные диалоги заменены на IDOK. Сработали нативный импорт сертификата, скрытый дочерний Windows PowerShell, регистрация MSIX 0.8.3, запись результата и сохранение доверия сертификату. Эта тестовая копия не публикуется.
- Подписи обоих опубликованных EXE, SHA-256, встроенный MSIX, версия, политика Run и совпадение встроенного приложения с переносимым — успешно.
- Полный WPF smoke suite и проверки автозапуска — успешно.
- Публичный updater скачал и проверил 0.8.3 для клиента 0.8.2; установщик на рабочем ПК не запускался.
- Сайт, ресурсы и обе ссылки скачивания — успешно. На VPS заменены только файлы скачивания и текст версии страницы; существовавшие контейнеры не перезапускались. Резервная копия: `/opt/b5mshot/deploy/downloads/backups/before-0.8.3-20260928-112511`.

```text
b464f2a934a59d0d9056286c0f96d95ede2e9e51bc8fc2fb4e76808ed101cc10  B5MShot.exe
4a142d1292c7d4bbb09733dfaef31adcebd7f0836dc15d203fa515c52e6245bf  B5MShot-Setup.exe
```

Ограничения: исходный конкретный сбой пользователей не воспроизведён. Тесты на hosted Windows не заменяют проверку всех клиентских Windows, защитных политик и разновидностей UAC. Для оставшихся ошибок нужны новый текст диалога и локальный журнал. Отложенная регистрация протестирована изолированно; реально занятый Проводник на пользовательском ПК не перезапускался.

Семантика занятых пакетов и отложенной регистрации сверена с [Microsoft Add-AppxPackage](https://learn.microsoft.com/en-us/powershell/module/appx/add-appxpackage) и [описанием ошибок развёртывания](https://learn.microsoft.com/en-us/windows/win32/appxpkg/troubleshooting).
