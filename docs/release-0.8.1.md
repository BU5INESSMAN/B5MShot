# B5MShot 0.8.1

## Выделение можно менять после захвата

- Перемещайте область мышью с инструментом «Переместить область» (M). После выделения он включён сразу.
- Меняйте размер за любой край или угол. Восемь контрастных маркеров показывают точки изменения размера.
- Стрелки перемещают область на 1 пиксель; Shift + стрелки меняют ширину/высоту; Ctrl увеличивает шаг до 10 пикселей.
- Esc во время перетаскивания отменяет только текущее перемещение/изменение размера.
- Рисунки, текст и мозаика остаются на своих местах относительно содержимого экрана. Уменьшение рамки не удаляет скрывшиеся правки: расширение возвращает их.
- Сохранение, копирование и публикация используют новую область в исходном разрешении. Рамка и инструменты в файл не попадают.

Изменение области доступно для захваченного экрана. Открытие готового файла по-прежнему запускает редактор изображения.

Обновление с 0.8.0 доступно через проверку обновлений в приложении. Установщик подписан прежним тестовым сертификатом; Windows может показать предупреждение. Сохраните снимки и завершите старую версию через трей перед ручной установкой.
