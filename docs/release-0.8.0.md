# B5MShot 0.8.0

- Выбор положения инструментов: сверху, снизу, слева или справа. Боковая панель вертикальная, значки остаются читаемыми.
- Выбор монитора или автоматическое размещение на мониторе с курсором. Отключённый монитор не мешает запуску.
- Палитра раскрывается внутрь экрана. Расположение сохраняется и применяется к выделению, редактору и открытым файлам.
- Новый стеклянный интерфейс настроек и трея, новые логотипы, плавные анимации и чёткая обводка выделения.
- Проверка GitHub Releases при запуске и каждые 6 часов, ручная проверка в настройках.
- Обновление из приложения: подтверждение, загрузка установщика, проверка SHA-256 и установка с подтверждением Windows. Открытый редактор не закрывается принудительно.
- Сохранение и копирование закрывают редактор только после успеха. Настройки сохраняются при обновлении.
- Улучшено открытие редактора, обработка быстрых переключений и режим отключённых системных анимаций.

## Установка

Сохраните открытые снимки и завершите старый B5MShot через трей. Скачайте **B5MShot-Setup.exe**, запустите и подтвердите запрос Windows. Приложение появится в трее, команда редактирования — в меню Проводника Windows 11.

**B5MShot.exe** — переносимая версия. Современная команда Проводника устанавливается только установщиком.

Установщик подписан тестовым сертификатом `CN=BU5INESSMAN`, как предыдущий выпуск. Это не сертификат публичного центра доверия: Windows/SmartScreen может показать предупреждение. Установка сертификата требует согласия и прав администратора.

## Новая настройка

Трей → Настройки → Панель инструментов → сторона и монитор → Сохранить.
При редактировании файла панель крепится к краю окна; при снимке экрана — к краю выбранного монитора.
