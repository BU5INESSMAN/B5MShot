# B5MShot 0.8.4 — обновление без ручного выхода из трея

- Установщик автоматически завершает фоновую копию B5MShot перед обновлением. Работа в трее больше не вызывает ошибку «программа работает в фоне».
- Новая версия при запуске может заменить более старую фоновую копию, даже если та успела первой занять горячие клавиши и блокировку единственного экземпляра.
- Автозапуск переносится на постоянный адрес установленного приложения, не зависящий от номера версии или расположения старого EXE.
- Открытые редакторы защищены: сначала сохраните снимок и закройте редактор. Выходить из трея не нужно. Неизвестные или зависшие процессы принудительно не завершаются.
- Если отменить установку, текущая версия остаётся работать в трее.

Подпись установщика пока тестовая. Системное подтверждение Windows остаётся необходимым.
