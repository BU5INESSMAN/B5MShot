# Проверка исправления автозапуска 0.8.2

28 сентября 2026. Исходники выпуска: `d5c4928d0f72c415fbbf657ef59049949518154e`, GitHub Actions `36389155859` (успешно).

## Причина и локальное исправление

В HKCU Run оставался путь к переносимой 0.6.0, хотя пакет 0.8.1 уже был зарегистрирован. Установщик не переносил Run; запись из MSIX-приложения могла попадать в изолированный реестр. Политика MSIX исправлена согласно [документации Microsoft](https://learn.microsoft.com/en-us/windows/msix/desktop/flexible-virtualization): ограниченное исключение Run в Windows 11, совместимый fallback в Windows 10.

Локальная запись заменена на активацию `shell:AppsFolder\BU5INESSMAN.B5MShot_mdepjvqy5n31g!B5MShot`. Существование идентификатора проверено через AppsFolder; подпись и версия установленного EXE проверены. Значение StartupApproved не изменялось. Резервная копия предыдущего значения находится локально в `release/autostart-backups/`. Старый процесс не завершался, установленный пакет не переустанавливался.

- Полный WPF smoke suite — успешно.
- Чистые проверки команд: постоянный идентификатор MSIX, независимость от версии папки, кавычки в переносимом пути, отказ для неверного идентификатора, отсутствие автоматического захвата автозапуска переносимой копией.
- Реальный фрагмент PowerShell из установщика выполнен с подменой единственного пути Run на временный тестовый ключ: перенос старого пути, повторный запуск, сохранение выключенного/пустого состояния, отказ для неверного пакета и сохранение посторонних значений — успешно. Настоящий Run при тестировании не менялся.
