# B5MShot

B5MShot — приложение для Windows, которое делает снимки экрана, позволяет сразу добавить пометки и загружает готовое изображение на `s.bu5inessman.ru`.

## Возможности

- работа в системном трее без лишней кнопки на панели задач;
- компактное окно управления по нажатию на значок в трее;
- снимок выбранной области или всего виртуального экрана;
- любые глобальные сочетания клавиш, включая возможность отключить действие;
- редактор: карандаш, линия, стрелка, рамка, текст и мозаика;
- копирование, сохранение PNG и публичная загрузка без пароля;
- автоматическое копирование ссылки на загруженный снимок;
- резервное подключение к VPS, если системный DNS не находит домен;
- проверка новых версий через GitHub Releases;
- журнал ошибок в `%LOCALAPPDATA%\B5MShot\logs\errors.log`;
- связь с разработчиком: [t.me/BU5INESSMAN](https://t.me/BU5INESSMAN).

## Использование

1. Запустите `B5MShot.exe`. Приложение появится в системном трее.
2. Нажмите `Print Screen` и выделите область экрана.
3. Добавьте пометки и нажмите «Загрузить», «Копировать» или «Сохранить».
4. Чтобы открыть настройки, щёлкните левой кнопкой по значку B5MShot в трее.
5. Для изменения горячей клавиши нажмите её поле, затем нажмите нужное сочетание. `Delete` отключает действие.

Настройки сохраняются в `%LOCALAPPDATA%\B5MShot\settings.json`. Адрес облака встроен в приложение и не показывается пользователю.

## Обновления

Клиент проверяет последний выпуск в `BU5INESSMAN/B5MShot` через GitHub Releases. Для корректной работы обновлений выпуск должен иметь тег вида `v0.4.1` и содержать файл `.exe`. При наличии новой версии приложение показывает предложение скачать её; установка без согласия пользователя не выполняется.

## Облако

- API: `https://s.bu5inessman.ru/api/screenshots`;
- состояние: `https://s.bu5inessman.ru/health`;
- изображения: `https://s.bu5inessman.ru/i/{id}`;
- хранилище на VPS: `/opt/b5mshot/deploy/data/screenshots`.

Загрузка публичная и не требует ключа. Сервер принимает только PNG/JPEG до 15 МБ и ограничивает один IP 30 загрузками в минуту.

## Структура

- `src/B5MShot.App` — Windows-клиент;
- `src/B5MShot.Server` — сервис загрузки;
- `deploy` — конфигурация Docker и Caddy;
- `.github/workflows` — автоматическая проверка сборки и создание выпусков.

## Сборка

Требуется .NET 8 SDK:

```powershell
dotnet build B5MShot.sln
dotnet publish src/B5MShot.App/B5MShot.App.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -p:EnableCompressionInSingleFile=true
```

Приложение пока не подписано сертификатом издателя, поэтому Windows SmartScreen может показать предупреждение при первом запуске.
