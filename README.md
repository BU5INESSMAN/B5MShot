# B5MShot

B5MShot — приложение для Windows, которое делает снимки экрана, позволяет сразу добавить пометки и загружает готовое изображение на `s.bu5inessman.ru`.

Скачать установщик: [B5MShot-Setup.exe](https://s.bu5inessman.ru/download/B5MShot-Setup.exe).

Переносимая версия без современного контекстного меню: [B5MShot.exe](https://s.bu5inessman.ru/download/B5MShot.exe).

## Возможности

- работа в системном трее без лишней кнопки на панели задач;
- настраиваемый автозапуск вместе с Windows;
- компактное окно управления по нажатию на значок в трее;
- снимок выбранной области или всего виртуального экрана;
- любые глобальные сочетания клавиш, включая возможность отключить действие;
- редактор: карандаш, линия, стрелка, рамка, текст и мозаика;
- панель инструментов с любой из четырёх сторон экрана, выбор монитора и раскрывающаяся внутрь палитра;
- `Ctrl+S` для сохранения и `Ctrl+C` для копирования готового снимка в редакторе;
- копирование, сохранение PNG и публичная загрузка без пароля;
- автоматическое копирование ссылки на загруженный снимок;
- открытие готового изображения в редакторе через основное контекстное меню Windows 11 или меню приложения в трее с последующей загрузкой;
- резервное подключение к VPS, если системный DNS не находит домен;
- проверка новых версий через GitHub Releases;
- журнал ошибок в `%LOCALAPPDATA%\B5MShot\logs\errors.log`;
- связь с разработчиком: [t.me/BU5INESSMAN](https://t.me/BU5INESSMAN).

## Использование

1. Запустите `B5MShot-Setup.exe`, подтвердите запрос UAC и установку тестового сертификата. После установки приложение появится в системном трее.
2. Нажмите `Print Screen` и выделите область экрана.
3. Добавьте пометки и нажмите «Загрузить», «Копировать» или «Сохранить».
4. Чтобы открыть настройки, щёлкните левой кнопкой по значку B5MShot в трее.
5. Для изменения горячей клавиши нажмите её поле, затем нажмите нужное сочетание. `Delete` отключает действие.
6. При необходимости включите «Запускать вместе с Windows» и нажмите «Сохранить».
7. Чтобы изменить и загрузить готовое изображение, нажмите по нему правой кнопкой мыши и выберите «Редактировать в B5MShot». У установленной версии команда находится в основном меню Windows 11. Переносимая версия показывает команду в разделе «Показать дополнительные параметры».

Настройки сохраняются в `%LOCALAPPDATA%\B5MShot\settings.json`. Адрес облака встроен в приложение и не показывается пользователю.

## Обновления

Клиент проверяет последний выпуск в [BU5INESSMAN/B5MShot](https://github.com/BU5INESSMAN/B5MShot) при запуске и каждые 6 часов; ручная проверка доступна в настройках. С версии 0.8.0 после подтверждения установщик скачивается в приложении, проверяется по SHA-256 и запускается с подтверждением Windows. Открытый редактор блокирует установку, чтобы не потерять снимок. Настройки сохраняются.

Выпуск содержит `B5MShot-Setup.exe`, `B5MShot.exe` и `SHA256SUMS.txt`, тег вида `v0.8.0`. Предварительные и черновые релизы не предлагаются как обновления. Установщик использует тестовый сертификат, не публично доверенную подпись.

Положение панели: **Настройки → Панель инструментов → сторона и монитор → Сохранить**. По умолчанию — сверху на мониторе с курсором. Для открытого файла используется край окна редактора.

## Облако

- API: `https://s.bu5inessman.ru/api/screenshots`;
- состояние: `https://s.bu5inessman.ru/health`;
- изображения: `https://s.bu5inessman.ru/i/{id}`;
- хранилище на VPS: `/opt/b5mshot/deploy/data/screenshots`.

Загрузка публичная и не требует ключа. Сервер принимает только PNG/JPEG до 15 МБ, ограничивает один IP 30 загрузками в минуту и одновременно обрабатывает не более четырёх загрузок.

### Политика хранения

Срок хранения не ограничен фиксированным количеством дней. Снимки сохраняются бессрочно, пока серверу хватает диска. Архив может вырасти до 70 ГБ; при достижении лимита удаляются самые старые файлы до уровня 65 ГБ. Независимо от размера архива сервер всегда резервирует минимум 20 ГБ свободного места и при очистке восстанавливает запас до 25 ГБ. Проверка выполняется каждые 30 минут и перед загрузкой, способной пересечь лимит. Незавершённые временные загрузки старше часа удаляются автоматически.

## Структура

- `src/B5MShot.App` — Windows-клиент;
- `src/B5MShot.ContextMenu` — нативная команда современного меню Проводника;
- `src/B5MShot.Setup` — установщик с тестовым сертификатом и пакетом приложения;
- `src/B5MShot.Server` — сервис загрузки;
- `packaging` — манифест и графические ресурсы установочного пакета;
- `deploy` — конфигурация Docker и Caddy;
- `.github/workflows` — автоматическая проверка сборки и создание выпусков.

## Сборка

Требуется .NET 8 SDK:

```powershell
dotnet build B5MShot.sln
dotnet publish src/B5MShot.App/B5MShot.App.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -p:EnableCompressionInSingleFile=true
```

Приложение пока не подписано сертификатом издателя, поэтому Windows SmartScreen может показать предупреждение при первом запуске.
