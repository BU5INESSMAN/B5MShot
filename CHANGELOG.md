# История изменений

## 0.8.0

- панель с четырёх сторон экрана, выбор монитора и сохранение расположения;
- вертикальные боковые инструменты и палитра, раскрывающаяся внутрь;
- единый стеклянный стиль приложения, трея, сайта и обновлённые логотипы;
- плавные прерываемые анимации, чёткая обводка и ускоренный захват;
- автоматическая проверка GitHub Releases и подтверждаемая установка с SHA-256;
- установщик больше не закрывает несохранённые редакторы принудительно;
- полноценный подписанный установщик, переносимая версия и контрольные суммы.

## 0.6.0

- добавлен единый установщик с подтверждением прав администратора;
- добавлена команда «Редактировать в B5MShot» в основном контекстном меню Windows 11;
- добавлено нативное расширение Проводника на базе `IExplorerCommand`;
- установленная версия использует современное меню, переносимая версия сохраняет совместимость со старым меню;
- тестовый сертификат автоматически добавляется установщиком и удаляется при неудачной установке;
- на сайте установщик стал основным вариантом загрузки, переносимая версия сохранена отдельно.

## 0.5.1

- изображения, открытые через Проводник, теперь сначала попадают в полноценный редактор B5MShot;
- загрузка в облако выполняется из редактора после внесения изменений;
- команда выбора файла в меню приложения переименована в «Открыть изображение…».

## 0.5.0

- ссылки на снимки теперь открывают фирменную страницу B5MShot с крупным предпросмотром;
- добавлены быстрое скачивание PNG, экспорт в JPG/WebP и копирование ссылки;
- добавлена загрузка локального изображения через контекстное меню Проводника «Загрузить в B5MShot»;
- добавлен выбор изображения для загрузки через меню значка B5MShot в трее;
- после загрузки локального изображения публичная ссылка автоматически копируется в буфер обмена.

## 0.4.2

- успешные `Ctrl+C` и `Ctrl+S` теперь автоматически закрывают редактор;
- отмена сохранения и ошибки оставляют редактор открытым.

## 0.4.1

- добавлена настройка запуска B5MShot вместе с Windows;
- добавлены `Ctrl+S` для сохранения и `Ctrl+C` для копирования в редакторе;
- добавлен лендинг программы на `s.bu5inessman.ru`;
- актуальная Windows-сборка опубликована по постоянной ссылке на домене.

## Сервер — адаптивное хранение

- добавлено бессрочное хранение до достижения лимита диска;
- добавлено удаление самых старых снимков при нехватке места;
- зарезервировано 20 ГБ свободного места для VPS;
- файлы распределяются по каталогам и записываются атомарно;
- сохранена совместимость со старыми ссылками;
- ограничены параллельные загрузки и память контейнера.

## 0.4.0

- добавлен ввод произвольных горячих клавиш;
- удалены пользовательские настройки облака;
- добавлены автоматическая и ручная проверки обновлений через GitHub;
- добавлено окно с описанием новой версии;
- добавлена кнопка сообщения об ошибке через Telegram;
- добавлена защита от повторного запуска приложения;
- добавлены журнал ошибок, повторные попытки работы с буфером обмена и безопасная запись настроек;
- исправлено состояние захвата полного экрана и обработка сетевых тайм-аутов;
- обновлён компактный дизайн окна настроек.
